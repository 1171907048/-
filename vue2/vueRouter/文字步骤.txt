1.在 Vue 项目中安装并引入 Vue Router 库 vue2的话，npm install --save vue-router@3，vue3的话install@4
2.在 src\router\index.js中，定义路由规则和组件的对应关系
//引入
import Router from 'vue-router'
//注册
Vue.use(Router)
//创建
const router = new Router({
  routes
})
//引入需要用的组件
import Home from '../views/vue2/homeView.vue' 
import About from '../views/vue2/aboutView.vue'
//路由与组件绑定
const routes = [{
    path: '/',
    name: 'Home',
    component: Home, //设置对应路径要加载的组件
  },
  {
    path: '/about',
    name: 'About',
    component: About
    //   component: () => import(/* webpackChunkName: "about" */ '../views/About.vue'),  //懒加载
  }
]
//将路由缺省暴露出去，其他文件才可访问
export default router; 
3.在src\main.js 中导入src\router\index.js，全局引入路由
//全局引入路由
import router from './router/index';
4.在APP.vue中使用当用户在 Home 和 About 页面之间切换时,组件状态会被缓存
=================================================================================
$route 每个组件自己的路由信息
$router 全局都一样，是路由的共用方法
=================================================================================
声明式路由导航 
 <router-link to="/">Home</router-link>  
 router-link
配置 to 属性指定路径(必须) 。本质还是a 标签，to 无需 #
to后面可以是path或name
 优点：简单直观，通过在模板中编写导航链接，不需要编写额外的Js代码。
编程式导航     this.$router.push('/')  优点：可以在Js代码中根据条件或动态数据进行导航，更加灵活和可控。
